#### Featured Projects

**[MonteCarloPerRadioterapia](https://github.com/AngeP02/MonteCarloPerRadioterapia)**

Monte Carlo photon transport simulator for radiotherapy dose calculation, implemented in **5 versions** across CPU and GPU.  
GPU V3 achieves 91% L1 cache hit rate using texture memory (vs 29–34% baseline). Validated against clinical LINAC 6 MV spectra (Sheikh-Bagheri & Rogers).  
`CUDA` `C++` `OpenMP` `HPC` `Jupyter`

`PySpark` `MLlib` `GraphFrames` `Streamlit` `PyDeck`
