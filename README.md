**[Monte carlo per Radioterapia](https://github.com/AngeP02/MonteCarloPerRadioterapia)**

`CUDA` `C++` `OpenMP` `HPC` `Jupyter`

`PySpark` `MLlib` `GraphFrames` `Streamlit` `PyDeck`
